# Практична Робота

**Тема:** Визначення та використання узагальнених методів.  
**Мета роботи:** Навчитися визначати та використовувати узагальнені методи в мові C#, зрозуміти, для чого потрібні обмеження параметра типу і як їх задавати, на прикладі самостійної розробки допоміжного класу для роботи з масивами.

## 8. Записати короткі висновки про те, як параметр типу та обмеження вплинули на реалізацію кожного з чотирьох методів

- **Метод IndexOf:** Оголошений без жодного обмеження `where`. Причина в тому, що для пошуку елемента в циклі викликається базовий метод `Equals()`, який є у всіх типах за замовчуванням від класу `Object`.
- **Метод Reverse:** Не вимагає звуження типів, оскільки алгоритм взагалі не перевіряє значення всередині масиву, а лише міняє їхні місця за допомогою тимчасової змінної `tmp`.
- **Метод Min:** Обов'язково потребує прив'язки до інтерфейсу `IComparable`. У C# звичайні знаки порівняння не працюють для невідомого узагальненого типу `T`, тому знаходити найменше значення доводиться через виклик методу `CompareTo()`.
- **Метод Max:** Працює на тій самій логіці з обмеженням `where T : IComparable`. Без наявності цього інтерфейсу компілятор видає помилку і не дозволяє визначити, який елемент більший.

## Питання для самоконтролю

### 1. Що таке узагальнений метод і чим він відрізняється від узагальненого класу?
Це звичайний метод, якому тип даних підкидають уже під час запуску. Різниця проста: в узагальненому класі тип обирається один раз для всього об'єкта одразу (і всі змінні всередині стають цього типу), а в узагальненому методі ми можемо передавати щоразу різні типи тільки для цієї однієї функції.

### 2. Який синтаксис використовується для оголошення параметра типу узагальненого методу?
Ставлять кутові дужки з літерою `T` прямо після імені методу, наприклад: `void Test<T>(T a)`.

### 3. Як компілятор визначає тип-аргумент під час виклику узагальненого методу, якщо він не вказаний явно?
Він сам здогадується. Дивиться, що саме ми запхали в круглі дужки при виклику: якщо передали туди звичайне число, компілятор сам зрозуміє, що замість `T` треба взяти `int`.

### 4. Для чого потрібні обмеження параметра типу?
Щоб компілятор не сварився, коли ми хочемо зробити з `T` щось більше, ніж просто перекласти з місця на місце. Обмеження дають йому зрозуміти, що цей тип гарантовано вміє, наприклад, порівнюватися або створюватися через `new`.

### 5. Як синтаксично задається обмеження параметра типу в C#?
Через слово `where` в самому кінці заголовка методу, наприклад: `void Fun<T>(T x) where T : IComparable`.

### 6. Чому метод IndexOf для масиву можна реалізувати без обмежень на параметр типу?
Бо для перевірки на рівність вистачає звичайного `Equals`, а він є взагалі у кожної змінної в C# від самого початку.

### 7. Чому методи Min і Max неможливо коректно реалізувати без обмеження параметра типу?
Тому що компілятор не вміє порівнювати невідомі типи через знаки більше і менше (`>` або `<`). Без `IComparable` він просто не знає, як зрозуміти, що з них більше, а що менше.

### 8. Що станеться під час компіляції, якщо викликати метод з обмеженням where T : IComparable<T> для типу, який цей інтерфейс не реалізує?
Програма просто не скомпілюється і видасть червону помилку внизу, що цей тип сюди не підходить.

### 9. Які ще види обмежень, крім IComparable<T>, можна накладати на параметр типу?
- `where T : class` — щоб передавати лише посилальні типи (наприклад, рядки чи класи);
- `where T : struct` — щоб передавати суто прості типи (числа, булеві значення);
- `where T : new()` — щоб усередині можна було спокійно створити новий об'єкт через `new T()`;
- `where T : ІмяБазовогоКласу` — щоб дозволити лише цей клас або його нащадків.

## Висновок
На практичній реалізував власний клас `ArrayHelper` без бібліотеки LINQ. Для методів `IndexOf` та `Reverse` жодних обмежень не задавав, бо для зміни позицій вистачає індексації масиву, а для пошуку — базового `Equals`. Для знаходження `Min` і `Max` додав `where T : IComparable`, оскільки компілятор не вміє порівнювати узагальнені типи без методу `CompareTo`. Роботу перевірив на `int` та `string`, усе працює коректно.
